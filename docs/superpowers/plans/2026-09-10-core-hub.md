# Core Hub Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build piece 1 of the dashboard — a laptop-first, one-screen daily hub (tasks, habits, weekly quotas, goals, 3-week history) that works offline and syncs between devices through a private GitHub repo.

**Architecture:** A static page served from GitHub Pages. Plain ES modules, split into pure logic (dates, parsing, scheduling, merging — all unit-tested under Node) and thin browser layers (storage, GitHub sync, DOM rendering). One JSON document in `localStorage` is the whole state; sync is GET → merge → PUT against one file in a private repo.

**Tech Stack:** HTML, CSS, JavaScript ES modules. Node 24's built-in `node:test` for tests. No npm dependencies, no build step, no framework. `python -m http.server` to serve locally.

**Spec:** [`docs/superpowers/specs/2026-09-10-core-hub-design.md`](../specs/2026-09-10-core-hub-design.md) — read it before starting any task.

## Global Constraints

- No build step, no framework, **no npm dependencies** (not even dev ones). `package.json` exists only for `"type": "module"` and the test script.
- Test command, from the repo root: `npm test` (runs `node --test tests/*.test.js`).
- `localStorage` keys: `dash_data` (the synced document), `dash_settings` (device-local: `token`, `repo`, `dayStartHour`; never synced).
- Document shape: `{schema: 1, items, goals, milestones, logs}`, each a map keyed by `id`.
- Every record carries `id`, `updated` (ISO timestamp), `source` (`me` · `claude` · `gemini` · `hebrew` · `notion`), `status` (`active` · `suggested` · `dismissed` · `archived`), `created` (logical day), `archivedOn` (logical day or `null`).
- Nothing is ever hard-deleted — archive, dismiss, or tombstone (`status: "archived"`).
- A logical day starts at **04:00** local time (`dayStartHour`, default 4). Weeks run Monday–Sunday. Days are `YYYY-MM-DD` strings.
- Sync store: private repo `dashboard-sync`, file `data.json`, GitHub Contents API, optimistic concurrency on `sha`, up to 3 attempts. Change-triggered sync is debounced 5 seconds.
- Phone layout below **760px**: the right column stacks under the list.
- Orange is used **only** for carry-over markers.
- Merge rule: per record, later `updated` wins; ties broken by comparing stable-stringified records.
